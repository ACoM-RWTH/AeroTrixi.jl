AeroTrixi.jl

AeroTrixi.jl is a package for high-fidelity aerodynamic simulations built on top of Trixi.jl. It adds pointwise surface quantities for aerodynamic applications, thermodynamics and entropy-conservative fluxes for multi-species flows of calorically imperfect gases, and a bridge to continuous finite elements of Gridap.jl for hyperbolic systems coupled to elliptic equations. In the future, we plan to add more features for nonideal and rarefied gases, for instance.

Features

  • Surface pressure and friction coefficients: the SurfacePointwiseCallback computes and saves pointwise aerodynamic coefficients along boundaries, such as SurfacePressureCoefficient and SurfaceFrictionCoefficient (see Surface quantities).
  • Thermodynamic data: tabulated internal energies and specific heats with interpolation and temperature inversion routines for multi-species flows in thermal equilibrium via ThermoData1T, with models for rotational and vibrational energies (see Thermodynamics).
  • Entropy-conservative/stable fluxes for non-calorically perfect multi-species flows: CompressibleEulerEquationsMs1T2D for 2D multi-species flows based on tabulated thermodynamic data, with the entropy-conservative flux flux_oblapenko_etal and its faster approximation flux_oblapenko_etal_taylor; chemical reactions are possible via source terms (see Multi-species equations).
  • Trixi.jl-Gridap.jl bridge: continuous finite element problems, assembled with Gridap.jl, solved on the adaptive P4estMesh of a DG simulation (2D, DG with polydeg = 2 and Q2 elements), with sources from and results written into the DG solution, on each Runge-Kutta stage via the GridapCallback; for example, the Euler equations of a charged gas, CompressibleEulerPoissonEquations2D (see the guide and the API).

Installation

AeroTrixi.jl is registered in the Julia General Registry. Install it using:

using Pkg
Pkg.add("AeroTrixi")

Examples

To get started, it is best to take a look at the examples in the folder returned by examples_dir, which run with trixi_include like the examples of Trixi.jl:
