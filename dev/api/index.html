API Reference

The functions and types of AeroTrixi.jl, grouped by topic:

  • Surface quantities: pointwise aerodynamic coefficients along boundaries
  • Thermodynamics: tabulated thermodynamic data and models for rotational and vibrational energies
  • Multi-species equations: Euler equations for multi-species flows of calorically imperfect gases and their fluxes
  • Trixi.jl-Gridap.jl bridge: continuous finite element problems on the adaptive mesh of a DG simulation (see also the guide)
AeroTrixi.AeroTrixi — Module
AeroTrixi

High-fidelity aerodynamic simulations with Trixi.jl.

source
AeroTrixi.examples_dir — Method
examples_dir()

Return the directory where the example files provided with AeroTrixi.jl are located. If AeroTrixi.jl is installed as a regular package (with ]add AeroTrixi), these files are read-only and should not be modified. To find out which files are available, use, e.g., readdir:

Examples

readdir(examples_dir())
