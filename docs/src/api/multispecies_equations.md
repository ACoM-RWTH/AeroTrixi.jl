# Multi-species equations

[`CompressibleEulerEquationsMs1T2D`](@ref) are the compressible Euler equations for
multi-species flows of calorically imperfect gases in thermal equilibrium, based on the
tabulated data of [`ThermoData1T`](@ref), with entropy-conservative fluxes and slip-wall
boundary conditions.
